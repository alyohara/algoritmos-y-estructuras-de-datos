# Algoritmos y Estructuras de Datos

Sitio estático que reúne el material de la cátedra: teoría, prácticas y cuadernos de Jupyter.

## Publicar con GitHub Pages

1. Subí esta carpeta a un repositorio de GitHub.
2. En el repositorio, abrí **Settings > Pages**.
3. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná la rama `main` y la carpeta `/(root)`.
4. Guardá los cambios. GitHub mostrará la URL pública cuando termine el despliegue.

El sitio no requiere instalación ni proceso de compilación. Los archivos de calificaciones, configuración local y copias duplicadas se excluyen mediante `.gitignore`.
