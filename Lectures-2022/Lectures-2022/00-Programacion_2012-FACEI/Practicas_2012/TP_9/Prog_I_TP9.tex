\begin{enumerate}

\item Realice una funci\'on/procedimiento recursivo que devuelva el factorial de un n\'umero.

\item Realice una funci\'on/procedimiento recursivo que encuentre el e\'nesimo t\'ermino de la serie de \emph{Fibonacci}.

\item Realice una funci\'on/procedimiento recursivo que dada una palabra la invierta.

\item Realice una funci\'on/procedimiento recursivo que devuelva a suma de todos los n\'umeros enteros de un vector.

\item Realice una funci\'on/procedimiento recursivo que cuente la cantidad de letras en una palabra.

\item Realice una funci\'on/procedimiento recursivo que sume los n\'umeros en el intervalo $[1..N]$.

\item Realice una funci\'on/procedimiento recursivo que encuentre un n\'umero dentro de un vector.

\item Implemente una versi\'on recursiva de la b\'usqueda binaria.

\item Realice una funci\'on/procedimiento recursivo que permita encontrar un valor dentro de una lista (enlazada).

\item Realice una funci\'on/procedimiento recursivo que sume los valores que se encuentran almacenados dentro de una lista (enlazada) de enteros.
    
\item Realice una funci\'on/procedimiento recursivo que de vuelta una lista (enlazada).

\item Realice una funci\'on/procedimiento recursivo que permita ordenar una lista (enlazada).


\end{enumerate}
